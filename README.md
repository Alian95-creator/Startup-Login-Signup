# Startup Login/Signup V3

> Modern startup-style frontend prototype for login & signup, ready for remote job portfolio

## Description
This project is an **interactive login and signup UI** with:  
- **“Book-opening” slide animation** for toggling between Login and Signup  
- **Animated gradient background** for a startup feel  
- **Input icons + hover/focus effects** for modern UX  
- **Login using FakeStore API**  
- **Signup simulation using localStorage**  

> Note: Signup is frontend-only simulation, suitable for demo & portfolio.

## Features
- Smooth toggle between Login / Signup forms

- Responsive design → looks good on desktop & mobile  
- Interactive hover/focus effects for inputs & buttons  
- Animated gradient background → startup-style look & feel
